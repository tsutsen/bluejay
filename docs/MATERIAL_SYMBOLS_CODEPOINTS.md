## How to Use

In Kotlin code, set the icon on a `TextView`:

```kotlin
textView.text = "\uE037"  // play_arrow
```

Or use the `Icons` mapping object:

```kotlin
textView.text = Icons.getIcon("play_arrow")
```

Or in XML with a `TextView`:

```xml
<TextView
    android:text="\uE037"
    android:fontFamily="@font/material_symbols_rounded"
    ... />
```
